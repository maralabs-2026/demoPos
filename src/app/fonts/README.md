# Fuentes

Archivos `.woff2` con el subset latin (incluye ñ, tildes y ¿¡), bajados de Google Fonts el 2026-11-05. Los carga `src/app/layout.tsx` con `next/font/local`.

| Archivo                         | Fuente                             | Licencia                                                                    |
| ------------------------------- | ---------------------------------- | --------------------------------------------------------------------------- |
| `dm-sans-latin-variable.woff2`  | DM Sans (variable, pesos 100–1000) | SIL Open Font License 1.1 — https://fonts.google.com/specimen/DM+Sans       |
| `manrope-latin-variable.woff2`  | Manrope (variable, pesos 200–800)  | SIL Open Font License 1.1 — https://fonts.google.com/specimen/Manrope       |
| `ibm-plex-mono-latin-500.woff2` | IBM Plex Mono 500                  | SIL Open Font License 1.1 — https://fonts.google.com/specimen/IBM+Plex+Mono |
| `ibm-plex-mono-latin-600.woff2` | IBM Plex Mono 600                  | SIL Open Font License 1.1 — https://fonts.google.com/specimen/IBM+Plex+Mono |

Para sumar un peso o un idioma, bajá el CSS de `https://fonts.googleapis.com/css2?family=...` con un navegador moderno, tomá la URL del bloque `/* latin */` y guardá el `.woff2` acá.
